# 知行工作台：墨色星图视觉系统

## 目标

本轮针对中文核心工作区的视觉与动效升级，不改变任务、知识、认领及复核接口契约。深墨色、纸白、玉绿与暖金组成主色；正文使用系统中文无衬线字体，展示标题采用系统中文衬线字体。字体文件、图标库和远程视觉资源不额外引入。

## 视觉组件

- 统一线性图标与几何品牌标识，替换导航中混杂的字符图标。
- 首页采用编辑式双栏：左侧工作理念与入口，右侧参数化环形线稿。线稿是知识循环的概念示意，不代表实时运行数据。
- 指标改为轻量连续分栏；任务卡片、项目、执行者、知识阅读和管理页共用边框、状态与表单体系。
- 任务中心增加阶段快捷条，复用原有真实筛选逻辑。
- 登录页采用独立双栏构图，保持原有凭证校验与访问边界。

## 动效规则

页面采用轻量淡入位移，侧栏使用滑动选中指示，卡片提供悬浮与按压反馈，任务详情使用侧向入场。知识线稿使用缓慢循环，轨道卫星运动用于表达持续循环。

装饰动效可通过顶栏暂停。系统设置“减少动态效果”时优先静止，并禁用装饰动效开关。窗口后台、线稿滚出可见范围时暂停循环。手机不使用鼠标悬浮作为唯一操作方式。

没有增加 WebGL、三维引擎、全屏粒子或动效框架。主要动效以 transform 和 opacity 实现。没有做设备级帧率认证，不能把轻量实现描述成任何设备上都不会掉帧。

## 可用性

提供墨色与纸白主题，本机保存偏好；中文正文与次级信息保持可读字号。支持 Ctrl/Command + K 聚焦任务搜索、Escape 关闭窄屏导航、导航抽屉焦点约束，以及减少动效偏好。

主题偏好仅存本机，不是账号级设置。任务阶段快捷条不会绕过服务端权限或验收。原始用户内容和技术标识不自动翻译。

## 验证与预览

浏览器回归继续使用实际生产构建与明确的虚构接口数据，覆盖原有功能并增加动态帧变化、暂停、主题保持、系统减少动效、快捷键、阶段筛选和窄屏检查。数据库协议仍由独立隔离集成测试验证。

预览导出包含实际页面 DOM 和同次构建的 CSS。离线交互演示只模拟界面，不连接生产服务，不保存真实任务，不启动智能体。正式交付状态以对应提交的 CI 结果为准。
